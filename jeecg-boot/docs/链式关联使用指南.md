# 链式关联使用指南

## 快速开始（5分钟上手）

链式关联功能让你可以在在线表单中显示关联表的字段值，无需在业务表中冗余存储数据。

**典型场景：** 工单表关联项目表，需要显示项目经理名称（存储在用户表中）

**核心特性：**
- ✅ 避免数据冗余
- ✅ 支持多级链式关联
- ✅ 列表页批量查询优化（性能提升100倍）
- ✅ 静默失败（查不出来返回空，不影响正常展示）
- ✅ 自动刷新机制

---

## 一、配置链式关联字段

### 1.1 单级链式关联

**场景：** 工单表需要显示项目经理名称

**步骤：**

1. **在在线表单中添加字段**
   - 字段名：`project_manager_name`
   - 字段类型：`link_table_chain`
   - 是否只读：是

2. **配置字段属性**
   - **字典表**（dictTable）：`sys_user`
   - **字典字段**（dictField）：`id`
   - **字典文本**（dictText）：`realname`

3. **配置扩展JSON**（fieldExtendJson）
   ```json
   {
     "valueFromField": "project_manager_id"
   }
   ```

**配置说明：**
- `valueFromField`：来源字段（当前表的字段，存储项目经理ID）
- `dictTable`：目标表（用户表）
- `dictField`：关联字段（用户表的ID字段）
- `dictText`：显示字段（用户表的姓名字段）

### 1.2 多级链式关联

**场景：** 工单表需要显示项目经理所在部门名称

**配置扩展JSON：**
```json
{
  "chain": [
    {
      "tableName": "common_module_project",
      "keyField": "id",
      "resultField": "project_manager_id"
    },
    {
      "tableName": "sys_user",
      "keyField": "id",
      "resultField": "depart_id"
    },
    {
      "tableName": "sys_depart",
      "keyField": "id",
      "resultField": "depart_name"
    }
  ],
  "valueFromField": "project_id"
}
```

**说明：**
- 第一级：从项目表查询项目经理ID
- 第二级：从用户表查询部门ID
- 第三级：从部门表查询部门名称

## 二、配置列表页显示

链式关联字段在表单详情页会自动显示，但在列表页需要额外配置。

### 2.1 配置Java增强

1. **进入在线表单设计页面**
   - 打开在线表单设计器
   - 选择需要配置的表单

2. **添加Java增强**
   - 点击"Java增强"标签
   - 点击"添加"按钮

3. **配置增强参数**
   - **按钮**：查询
   - **事件**：结束
   - **类型**：spring-key
   - **内容**：`linkTableChainListEnhance`

4. **保存配置**

### 2.2 验证配置

**表单详情页：**
- 打开表单详情页
- 链式关联字段应自动显示派生值
- 来源字段变化时，派生字段自动更新

**列表页：**
- 打开表单列表页
- 链式关联字段列应显示派生值
- 性能优化：使用批量查询，响应速度快

## 三、前端集成（可选）

如果你需要在自定义前端组件中使用链式关联功能，可以使用提供的辅助工具。

### 3.1 导入工具函数

```typescript
import {
  fillLinkChainFieldsForForm,
  handleLinkChainFieldChange,
  refreshLinkChainFields
} from '/@/utils/workflow/linkChainHelper';
```

### 3.2 表单加载时填充

```typescript
// 在表单加载完成后调用
await fillLinkChainFieldsForForm(fields, formData);
```

### 3.3 监听字段变化

```typescript
// 监听来源字段变化，自动更新派生字段
watch(() => formData.project_manager_id, async () => {
  await handleLinkChainFieldChange(fields, formData, 'project_manager_id');
});
```

### 3.4 手动刷新

```typescript
// 添加刷新按钮
const handleRefresh = async () => {
  const refreshedData = await refreshLinkChainFields(tableName, formData);
  Object.assign(formData, refreshedData);
  message.success('刷新成功');
};
```

## 五、故障排查

### 5.1 链式字段不显示

**可能原因：**
1. 目标表未配置为在线表单
2. 字段配置不完整
3. 来源字段值为空

**解决方法：**
1. 确保目标表已导入到在线表单（或从 `exclude_table` 中移除 `sys_` 前缀）
2. 检查 `dictTable`、`dictField`、`dictText`、`valueFromField` 是否都已配置
3. 检查来源字段是否有值

### 5.2 列表页不显示链式字段

**可能原因：**
1. 未配置Java增强
2. Java增强配置错误

**解决方法：**
1. 检查是否已添加Java增强配置
2. 确认配置参数：
   - 按钮：查询
   - 事件：结束
   - 类型：spring-key
   - 内容：`linkTableChainListEnhance`

### 5.3 系统表无法导入

**问题：** `sys_user` 等系统表无法在"导入表"功能中找到

**解决方法：**
1. 编辑 `jeecg_config.properties`
2. 从 `exclude_table` 中移除 `sys_`
   ```properties
   # 修改前
   exclude_table=act_,ext_act_,design_,onl_,sys_,qrtz_
   # 修改后
   exclude_table=act_,ext_act_,design_,onl_,qrtz_
   ```
3. 重启应用

### 5.4 性能问题

**问题：** 列表页加载很慢

**解决方法：**
1. 确认已配置Java增强（使用批量查询）
2. 检查数据库索引（关联字段应有索引）
3. 减少链式关联字段数量

## 六、注意事项

### 6.1 安全机制

- **表名白名单**：只能查询已配置为在线表单的表
- **字段白名单**：只能查询表单元数据中定义的字段
- **参数化查询**：防止SQL注入

### 6.2 静默失败

- 所有链式关联查询失败都静默处理
- 查不出来返回 null，不影响正常业务流程
- 错误信息记录在日志中

### 6.3 性能优化

- **列表页**：自动使用批量查询（IN 语句）
- **表单详情页**：多个链式字段并发查询
- **性能提升**：100条记录，3个链式字段，从300次查询优化到3次查询

### 6.4 字段刷新

- **自动刷新**：来源字段变化时自动更新派生字段
- **手动刷新**：提供刷新接口，支持批量刷新
- **实时性**：表单详情页实时计算，列表页在查询时计算

## 七、最佳实践

### 7.1 字段命名规范

- 来源字段：`xxx_id`（如：`project_manager_id`）
- 派生字段：`xxx_name`（如：`project_manager_name`）

### 7.2 性能优化建议

1. **减少链式层级**：尽量控制在2-3级以内
2. **添加数据库索引**：关联字段应有索引
3. **合理使用**：只在必要时使用链式关联

### 7.3 数据一致性

- 链式关联是实时查询，不存储派生值
- 源数据变化时，派生值自动更新
- 无需担心数据不一致问题

```json
{
  "chain": [
    {
      "tableName": "common_module_project",
      "keyField": "id",
      "resultField": "project_manager_id"
    },
    {
      "tableName": "sys_user",
      "keyField": "id",
      "resultField": "realname"
    }
  ],
  "valueFromField": "project_id"
```

**3. Java增强配置**
